常见问题

关于协议、技术选型与部署。

可以商用吗？

可以。项目采用 MIT 协议，允许商用、修改、二次分发，只需保留版权声明。

和 RuoYi 等传统后台框架有什么区别？

技术栈不同：WeJava Admin 基于 Spring Boot 4.1、Spring Security 7 与 Jackson 3，前端是 Vue 3.5 组合式 API。权限设计与传统框架不同：接口层用 @PreAuthorize 校验，数据权限通过 SQL 解析改写而不是在业务代码里手写条件。此外内置了多服务商 AI 助手。

怎么部署到自己的服务器？

三种方式：一是 docker compose up -d 一键启动；二是打包 WAR 部署到 Tomcat 11 并用 Nginx 反向代理；三是本地开发，Maven 与 pnpm 分别启动。详细步骤见仓库 docs/07-部署方案.md。

需要什么环境？

JDK 17、MySQL 8.4+、Redis 7+；前端构建需要 Node 20+ 与 pnpm。使用 Docker 时无需预装。
