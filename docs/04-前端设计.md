## 四、路由设计

### 4.1 静态路由（constantRoutes）

```ts
export const constantRoutes: RouteRecordRaw[] = [
  { path: '/login', component: () => import('@/views/login/index.vue'), meta: { hidden: true } },
  { path: '/404', component: () => import('@/views/error/404.vue'), meta: { hidden: true } },
  { path: '/403', component: () => import('@/views/error/403.vue'), meta: { hidden: true } },
  { path: '/redirect/:path(.*)', component: () => import('@/layout/components/Redirect.vue'), meta: { hidden: true } },
  { path: '/', component: Layout, redirect: '/dashboard',
    children: [{ path: 'dashboard', component: () => import('@/views/dashboard/index.vue'),
                 meta: { title: '首页', icon: 'home', affix: true } }] }
]
```

### 4.2 动态路由（后端返回 → 前端转换）

后端 `/auth/routers` 返回的 `component` 是字符串（如 `system/user/index`），前端需要映射成组件：

```ts
const modules = import.meta.glob('@/views/**/*.vue')

function resolveComponent(component: string) {
  if (!component || component === 'Layout') return Layout
  if (component === 'InnerLink') return InnerLink
  const path = `/src/views/${component}.vue`
  if (!modules[path]) {
    console.error('[router] 组件不存在:', path)
    return () => import('@/views/error/404.vue')
  }
  return modules[path]
}
```

### 4.3 路由守卫（关键）

```ts
const whiteList = ['/login', '/404', '/403']

router.beforeEach(async (to, from, next) => {
  NProgress.start()
  const userStore = useUserStore()
  const permStore = usePermissionStore()

  if (!userStore.token) {
    // 未登录
    if (whiteList.includes(to.path)) return next()
    return next(`/login?redirect=${encodeURIComponent(to.fullPath)}`)
  }

  // 已登录，但用户信息未加载（首次进入或刷新）
  if (!userStore.loaded) {
    try {
      await userStore.getInfo()                 // /auth/me
      const routes = await permStore.generateRoutes()   // /auth/routers
      routes.forEach(r => router.addRoute(r))
      // ★ replace: true 重新走一遍导航，确保新路由已注册
      return next({ ...to, replace: true })
    } catch (e) {
      await userStore.resetToken()
      return next(`/login?redirect=${encodeURIComponent(to.fullPath)}`)
    }
  }

  // 已登录且路由就绪，但访问的路径不存在
  if (to.matched.length === 0) {
    return next('/404')
  }

  next()
})

router.afterEach(() => NProgress.done())
```

**三个必须注意的点**：

1. `next({ ...to, replace: true })` 之后不能再写 `next()`，否则会重复导航
2. 白名单必须包含 `/login`，否则 401 跳登录页时会死循环
3. 404 兜底路由要**动态添加**（在 `addRoute` 最后加 `{ path: '/:pathMatch(.*)*', redirect: '/404' }`），不能写在 `constantRoutes` 里，否则动态路由永远匹配不到

## 五、登录与 Token

### 5.1 Token 存储

| 项 | 位置 | 说明 |
|---|---|---|
| `accessToken` | Pinia + localStorage | 刷新页面不丢 |
| `refreshToken` | Pinia + localStorage | 同上 |

> 不推荐存 Cookie：跨域配置复杂，且 JWT 在 Header 里天然免疫 CSRF。
> 但如果安全要求高，应存**内存**（不落 localStorage），代价是刷新页面要重新登录。

### 5.2 登录页流程

```ts
async function handleLogin() {
  await formRef.value?.validate()
  loading.value = true
  try {
    const { data } = await loginApi({
      username: form.username,
      password: form.password,
      captchaKey: captcha.key,
      captchaCode: form.captchaCode
    })
    userStore.setToken(data.accessToken, data.refreshToken, data.expiresIn)
    await router.push(redirect.value || '/')
  } catch {
    refreshCaptcha()       // 登录失败必须换验证码
  } finally {
    loading.value = false
  }
}
```

> 登录失败后**必须刷新验证码**（后端一次性使用），否则用户第二次提交一定失败。

## 六、axios 封装（本项目最容易写错的地方）

### 6.1 刷新队列

```ts
// utils/request.ts
import axios, { type AxiosRequestConfig, type InternalAxiosRequestConfig } from 'axios'
import { ElMessage } from 'element-plus'
import { useUserStore } from '@/store/modules/user'
import router from '@/router'

const service = axios.create({
  baseURL: import.meta.env.VITE_APP_BASE_API,
  timeout: 15000
})

// ---- 刷新队列状态 ----
let isRefreshing = false
let waitingQueue: Array<(token: string) => void> = []

function onTokenRefreshed(newToken: string) {
  waitingQueue.forEach(cb => cb(newToken))
  waitingQueue = []
}

// ---- 请求拦截 ----
service.interceptors.request.use((config: InternalAxiosRequestConfig) => {
  const userStore = useUserStore()
  if (userStore.accessToken) {
    config.headers.Authorization = `Bearer ${userStore.accessToken}`
  }
  return config
})

// ---- 响应拦截 ----
service.interceptors.response.use(
  (response) => {
    const res = response.data
    if (res.code === 200) return res

    // 业务错误
    ElMessage.error(res.msg || '操作失败')
    return Promise.reject(new Error(res.msg))
  },
  async (error) => {
    const { response, config } = error
    const userStore = useUserStore()

    if (!response) {
      ElMessage.error('网络异常，请稍后重试')
      return Promise.reject(error)
    }

    // ★ 401：区分"过期"与"失效"
    if (response.status === 401) {
      const code = response.data?.code

      // 1005 = access 过期 → 静默刷新
      if (code === 1005 && !config._retry && userStore.refreshToken) {
        config._retry = true

        if (isRefreshing) {
          // 刷新中：挂起，等新 token 到了重放
          return new Promise((resolve) => {
            waitingQueue.push((token: string) => {
              config.headers.Authorization = `Bearer ${token}`
              resolve(service(config))
            })
          })
        }

        isRefreshing = true
        try {
          const { data } = await refreshTokenApi(userStore.refreshToken)
          userStore.setToken(data.accessToken, data.refreshToken, data.expiresIn)
          onTokenRefreshed(data.accessToken)
          config.headers.Authorization = `Bearer ${data.accessToken}`
          return service(config)
        } catch (e) {
          waitingQueue = []
          await userStore.resetToken()
          router.push(`/login?redirect=${encodeURIComponent(router.currentRoute.value.fullPath)}`)
          return Promise.reject(e)
        } finally {
          isRefreshing = false
        }
      }

      // 1006 或刷新失败 → 直接登出
      waitingQueue = []
      await userStore.resetToken()
      router.push(`/login?redirect=${encodeURIComponent(router.currentRoute.value.fullPath)}`)
      return Promise.reject(error)
    }

    // ★ 403 绝对不能跳登录页
    if (response.status === 403) {
      ElMessage.error('无访问权限')
      return Promise.reject(error)
    }

    ElMessage.error(response.data?.msg || `请求失败 (${response.status})`)
    return Promise.reject(error)
  }
)

export default service
```

**这段代码的三个关键点**：

1. **`config._retry`** 防止刷新后的请求再次 401 导致无限递归
2. **`isRefreshing` + `waitingQueue`** 保证并发 10 个 401 只刷新 1 次
3. **403 不跳登录页** —— 跳了必死循环

## 七、权限控制

### 7.1 工具函数

```ts
// utils/permission.ts
import { useUserStore } from '@/store/modules/user'

export function hasPerm(perm: string | string[]): boolean {
  const perms = useUserStore().perms
  if (perms.includes('*:*:*')) return true            // 超管
  const list = Array.isArray(perm) ? perm : [perm]
  return list.some(p => perms.includes(p))
}

export function hasRole(role: string | string[]): boolean {
  const roles = useUserStore().roles
  if (roles.includes('admin')) return true
  const list = Array.isArray(role) ? role : [role]
  return list.some(r => roles.includes(r))
}
```

### 7.2 指令

```ts
// directives/hasPerm.ts
import type { Directive, DirectiveBinding } from 'vue'
import { hasPerm } from '@/utils/permission'

export const hasPermDirective: Directive = {
  mounted(el: HTMLElement, binding: DirectiveBinding) {
    if (!hasPerm(binding.value)) {
      el.parentNode?.removeChild(el)
    }
  }
}
```

```vue
<el-button v-hasPerm="'system:user:add'" type="primary" @click="handleAdd">
  新增
</el-button>
```

> **指令只是隐藏按钮，不是安全边界。** 后端每个接口都必须有 `@PreAuthorize`。

## 八、Pinia Store

```ts
// store/modules/user.ts
export const useUserStore = defineStore('user', () => {
  const accessToken = ref(localStorage.getItem('accessToken') || '')
  const refreshToken = ref(localStorage.getItem('refreshToken') || '')
  const user = ref<UserInfo | null>(null)
  const roles = ref<string[]>([])
  const perms = ref<string[]>([])
  const loaded = ref(false)

  function setToken(access: string, refresh: string, _expiresIn: number) {
    accessToken.value = access
    refreshToken.value = refresh
    localStorage.setItem('accessToken', access)
    localStorage.setItem('refreshToken', refresh)
  }

  async function getInfo() {
    const { data } = await getMe()
    user.value = data.user
    roles.value = data.roles
    perms.value = data.perms
    loaded.value = true
  }

  async function resetToken() {
    accessToken.value = ''
    refreshToken.value = ''
    user.value = null
    roles.value = []
    perms.value = []
    loaded.value = false
    localStorage.removeItem('accessToken')
    localStorage.removeItem('refreshToken')
    usePermissionStore().reset()
  }

  return { accessToken, refreshToken, user, roles, perms, loaded, setToken, getInfo, resetToken }
})
```

```ts
// store/modules/permission.ts
export const usePermissionStore = defineStore('permission', () => {
  const routes = ref<RouteRecordRaw[]>([])
  const sidebarRoutes = ref<RouteRecordRaw[]>([])

  async function generateRoutes() {
    const { data } = await getRouters()
    const dynamic = transformRoutes(data)
    routes.value = dynamic
    sidebarRoutes.value = filterHidden(dynamic)
    return [
      ...dynamic,
      { path: '/:pathMatch(.*)*', redirect: '/404', meta: { hidden: true } }  // ★ 最后加
    ]
  }

  function reset() {
    routes.value = []
    sidebarRoutes.value = []
  }

  return { routes, sidebarRoutes, generateRoutes, reset }
})
```

## 九、布局与多页签

| 组件 | 职责 |
|---|---|
| `layout/index.vue` | 整体骨架：侧边栏 + 顶栏 + 标签页 + 内容区 |

```vue

    <component :is="Component" :key="route.path" />

</router-view>
```

## 十、列表页通用逻辑（useTable）

```ts
export function useTable<T>(api: (params: any) => Promise<R<PageResult<T>>>, initParams = {}) {
  const loading = ref(false)
  const list = ref<T[]>([])
  const total = ref(0)
  const query = reactive({ pageNum: 1, pageSize: 10, ...initParams })

  async function getList() {
    loading.value = true
    try {
      const { data } = await api(query)
      list.value = data.list
      total.value = data.total
    } finally {
      loading.value = false
    }
  }

  function handleSearch() { query.pageNum = 1; getList() }
  function handleReset() {
    Object.assign(query, { pageNum: 1, pageSize: 10, ...initParams })
    getList()
  }

  onMounted(getList)
  return { loading, list, total, query, getList, handleSearch, handleReset }
}
```

**约定**：所有列表页统一"查询 / 重置 / 分页"三件套，删除后若当前页为空则回退一页。

## 十二、前端自检清单

- [ ] 任意子路由刷新不 404、不白屏
- [ ] 并发 10 个 401 只触发 1 次刷新
- [ ] 403 不跳登录页
- [ ] 登出后返回登录页，浏览器后退不能回到业务页
- [ ] 无权限按钮不可见，且直接调接口返回 403
- [ ] 多页签切换时表单内容保留（keep-alive 生效）
- [ ] 表格分页参数为 `pageNum` / `pageSize`，与后端一致
- [ ] 所有 `id` 按 string 处理，不使用 `Number(id)`
- [ ] 列表接口的 `beginTime` / `endTime` 格式为 `yyyy-MM-dd HH:mm:ss`
- [ ] 生产包不含 `console.log`、不含 sourcemap（或单独上传）
- [ ] 首屏体积 < 1MB（gzip 后）
- [ ] 上传组件限制大小和类型，与后端白名单一致
